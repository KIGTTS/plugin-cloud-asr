# Source origin

This repository is an independent KIGTTS plugin. Its service shell is derived from the KIGTTS recognition-service source at commit 36e4d8fbb1a199009c01c95ae65f4e97b1759e81; the original MIT notices are preserved. Cloud provider configuration, HTTPS request adapter and user-selected endpoint model were added here. The SDK is pinned as a submodule and no credentials or user data are included.
